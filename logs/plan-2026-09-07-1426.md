## Goal

데스크톱 Usage Log를 안전한 운영 관찰 가능성(observability) 뷰로 확장합니다.

## Actions

- 기존 사용량 기록(providers, 결과, 모델/경로) 필터 기능을 추가했습니다.
- 요청별 시도 상세 내역(경로, HTTP 상태, 실패 분류, 지연 시간, 토큰 합계)을 접이식 테이블로 표시하도록 했습니다.
- 프롬프트, 응답, 인증 정보, 인증 헤더, 요청 본문 등 민감 정보는 렌더링 대상에서 제외했습니다.
- 프론트엔드 테스트에 Usage Log 필터링 커버리지를 추가했습니다.
- 데스크톱 프론트엔드 테스트 스위트를 성공적으로 실행했습니다.

## Files Changed

- `desktop/frontend/app.js`: Usage Log 필터 및 접이식 시도 테이블 추가
- `desktop/frontend/app.test.js`: Usage Log 필터링 커버리지 테스트 추가

## Result

- 성공: `npm.cmd test --prefix desktop` 3개 테스트 모두 통과
- 저장된 사용량 이력은 필터링 가능하며, 안전한 폴백 시도 검사(fallback-attempt inspection)를 지원합니다.

- 릴레이 구현 후 전체 네이티브 및 프론트엔드 검증 실행
