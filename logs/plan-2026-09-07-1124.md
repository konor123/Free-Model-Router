# 빌드 및 배포 로그

## Goal

Windows용 실행 파일과 이동식 ZIP 설치 패키지를 준비하여 사용자가 직접 E2E 테스트를 수행할 수 있도록 한다.

## Actions

- `scripts/package-windows.ps1`를 사용하여 Windows amd64용 게이트웨이 실행 파일과 제어 CLI를 빌드함
- 사이드카 메타데이터, 패키지 매니페스트, JSON 스키마를 생성함
- 버전 `dev-82d83d3`의 이동식 ZIP 패키지를 생성함
- `go run ./cmd/fmr-package -validate`로 게이트웨이 바이너리 해시, 메타데이터, 매니페스트를 검증함

## Files Changed

- `dist/windows/Free-Model-Router.exe`: 게이트웨이 실행 파일
- `dist/windows/fmr.exe`: 제어 CLI 실행 파일
- `dist/windows/Free-Model-Router.exe.metadata.json`: 사이드카 메타데이터
- `dist/windows/manifest.json`: 이동식 패키지 매니페스트
- `dist/windows/manifest.schema.json`: 매니페스트 스키마
- `dist/Free-Model-Router-dev-82d83d3-windows-amd64.zip`: 이동식 설치 패키지

## Result

- 성공: 이동식 패키지 검증 통과
- ZIP 파일은 수동 압축 해제 후 E2E 테스트에 사용 가능하며, 데스크톱 Tauri 실행 파일은 포함되어 있지 않음

## Next Steps

- 사용자가 ZIP을 압축 해제한 후 해당 디렉토리에서 `fmr.exe start`를 실행할 수 있음
- 생성된 `dist/` 아티팩트는 명시적으로 요청하지 않는 한 Git에 포함하지 않음
