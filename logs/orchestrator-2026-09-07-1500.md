## Goal

Add a configurable OpenAI-compatible provider adapter and wire persisted enabled providers into application startup.

## Actions

- Added an OpenAI-compatible adapter that remaps catalog identities to configured provider namespaces.
- Added per-instance bearer transport injection and disabled redirects.
- Added application factory that builds an immutable registry from enabled ProviderConfig entries while retaining anonymous built-in OpenCode behavior.
