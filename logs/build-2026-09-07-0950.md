## Goal

로컬 C 컴파일러를 설치하여 Go race 감지기가 작동하도록 하고, 이전에 차단되었던 race 검증을 완료합니다.

## Actions

- WinGet을 통해 사용자 범위 `BrechtSanders.WinLibs.POSIX.UCRT` 패키지를 설치했습니다.
- 검증 프로세스에만 `CC`, `CGO_ENABLED` 및 PATH를 구성했습니다.
- GCC 16.1.0이 `x86_64-w64-mingw32`를 대상으로 하는지 확인했습니다.
- `go test -race ./...`를 성공적으로 실행했습니다.

## Files Changed

- 이번 단계에서 변경된 저장소 소스 또는 구성 파일은 없습니다.

## Result

- 성공: 모든 저장소 패키지가 race 감지기 검증을 통과했습니다.
- GCC 설치는 사용자 범위로 수행되었으며, 향후 셸에서 `gcc`를 직접 호출하기 전에 PATH를 새로고침해야 할 수 있습니다.
