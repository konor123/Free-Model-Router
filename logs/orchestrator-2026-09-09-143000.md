## Goal

Provider 편집 draft가 상태 새로고침에 의해 사라지는 문제를 해결하고 API key 입력을 UI 상태에서 분리한다.

## Actions

- 서버 확정 설정과 provider draft 상태를 분리했다.
- provider 행에 편집 불가능한 clientKey를 도입했다.
- API key replacement/clear intent를 모듈 내부 ephemeral map으로 분리했다.
- dirty draft 중 provider refresh가 편집 form을 교체하지 않게 했다.
- 저장 중복 방지, unique ID 검증, 저장 실패 후 draft 유지, discard 동작을 추가했다.
- benchmark Performance가 routing score만으로 표시되지 않도록 explicit `performanceKnown`을 요구하게 했다.
- frontend 테스트를 추가하고 통과시켰다.
