## Goal

OpenCode Zen 유료 모델이 무료 익명 카탈로그에 포함되는 문제와 FMR Desktop 실행 시 CMD 창이 나타나는 문제를 해결한다.

## Actions

- OpenCode 공식 가격 문서 기준 무료 모델 6개 exact allowlist를 추가했다.
- native OpenCode catalog, route 생성, completion 단계에 allowlist를 적용해 유료·미확인 모델을 fail-closed 처리했다.
- Desktop SecretStore의 Zen key를 native OpenCode instance-local resolver로 연결해 Public과 Zen 무료 route를 함께 사용하도록 수정했다.
- generic OpenAI-compatible provider는 native 무료 정책에서 제외했다.
- native OpenCode HTTP redirect를 차단하고 Zen credential은 Zen 요청에만 전송하도록 유지했다.
- Windows managed sidecar 실행에 CREATE_NO_WINDOW를 적용했다.
- Start with Windows를 HKCU Run registry 값으로 전환하고 legacy CMD cleanup을 best-effort로 처리했다.
- README에 OpenCode catalog 정책을 추가했다.
- Tester와 reviewer 검토를 완료했다.
