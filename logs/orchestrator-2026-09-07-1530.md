# 로그: desktop control-plane/UI 개선 - SSE 기반 Usage Log

## Goal

계획된 desktop control-plane/UI 개선 사항을 SSE 기반 Usage Log 업데이트를 통해 검증 완료한다.

## Actions

- 모델 풀 교체, 고정(auto-pinning), 자동 선택, 설정 조회를 위한 네이티브 인증 제어 명령 추가
- 모델 매니저 검색/필터링, 일괄 선택 액션, 고정/고정해제, 자동 선택, 변경 이력 피드백 및 집중 프론트엔드 테스트 구현
- Usage Log 메타데이터 필터 및 프롬프트/응답/요청 본문/자격 증명/인증 헤더를 렌더링하지 않는 확장 가능한 안전한 시도 상세 정보 구현
- Rust 소유 인증 SSE usage-event 릴레이 구현. 프론트엔드는 네이티브 이벤트를 수신하고 영속화된 `gateway_logs` REST 엔드포인트를 통해 표시되는 이력을 조정
- 코드 리뷰 발견 사항 해결: 라우트 필터는 하나 이상의 라우트 매칭 필요; Usage Log 검색은 테이블 행만 다시 그리기; 풀 변경 오류는 새로고침 후에도 유지; 스트림 시작 시 연결 먼저 검증; 읽기 타임아웃은 종료 응답성 허용; 원시 HTTP 토큰은 연결/요청 생성 전 제어 문자 거부
- 포맷터 및 프론트엔드/네이티브 테스트 검증 실행; 독립적 리뷰 완료

## Files Changed

- `desktop/src-tauri/src/main.rs`: 인증된 제어 브리지 명령, SSE 릴레이, 생명주기 가드, bearer 토큰 검증, Rust 테스트 추가
- `desktop/frontend/app.js`: 모델 매니저 제어, Usage Log 필터링/시도 확장, 네이티브 usage-event 조정 추가
- `desktop/frontend/app.test.js`: 모델 매니저 및 Usage Log 필터링 테스트 추가

## Result

- **성공**: 프론트엔드 테스트 통과 (3개 테스트); Rust 포맷터 통과; Rust 네이티브 셸 테스트 통과 (11개 테스트)
- 독립적 리뷰에서 최종 원시 HTTP 토큰 검증 수정에 대한 잔여 차단 문제 없음 확인
- **잔여 검증 격차**: 이 환경에서 실시간 Tauri GUI + 게이트웨이 SSE 종단 간 세션은 실행되지 않음

- 릴리스 전 데스크톱 릴리스 빌드/패키지 검증 실행 또는 요청 시 검증된 변경 사항 커밋
