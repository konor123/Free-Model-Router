## Goal

OpenCode 무료 카탈로그 및 Desktop no-console 수정본을 Windows 패키지로 빌드·검증하고 커밋 준비를 완료한다.

## Actions

- Tauri release binary, NSIS installer, MSI installer 빌드를 완료했다.
- Windows portable ZIP 패키지를 생성했다.
- sidecar metadata와 manifest를 `fmr-package -validate`로 검증했다.
- release desktop executable과 portable package 내 executable SHA256 일치를 확인했다.
- 이전 패키지 실행 파일 잠금 문제는 사용자가 해당 FMR Desktop을 정상 종료한 뒤 재시도로 해결했다.
