## Goal

검토에서 승인된 수정 사항을 기존 도구/reasoning 전달, 헬스 취소, CI 보호 기능을 보존하면서 구현한다.

## Actions

- 현재 작업 트리에서 이미 구현된 네 가지 승인 항목을 확인: 도구/reasoning 전달, `boolOr` 기본값, 취소 인식 헬스 슬롯, CI 경합/검사
- 게이트웨이 자동 모델 선택을 결정적으로 만들기 위해 프로바이더 모델 ID를 정렬한 후 첫 번째 항목을 선택하도록 변경
- OpenCode 프로바이더에 2분 기본 HTTP 클라이언트 타임아웃을 추가
- 클라이언트 데드라인 에러를 `FailureTimeout`로 분류하면서 요청 컨텍스트 취소 분류는 유지
- 회귀 테스트를 추가하고, 집중 테스트에서 발견된 누락된 표준 라이브러리 import를 수정

## Files Changed

- `internal/gateway/gateway.go`: 자동 라우팅을 위해 카탈로그 새로고침 시 사전순으로 정렬된 첫 번째 모델을 선택
- `internal/gateway/gateway_test.go`: 카탈로그 새로고침 전반에 걸친 결정적 자동 모델 선택 테스트 커버리지 추가
- `internal/providers/opencode/provider.go`: 카탈로그 타임아웃 분류를 포함한 기본 HTTP 타임아웃 설정 및 적용
- `internal/providers/opencode/chat.go`: 프로바이더 클라이언트 타임아웃을 타임아웃 실패로 분류
- `internal/providers/opencode/opencode_test.go`: 기본 타임아웃 설정 및 채팅 타임아웃 분류 테스트 커버리지 추가

## Result

- 집중 테스트 통과: `go test ./internal/gateway ./internal/providers/opencode ./internal/health`
- 누락된 `errors` import로 인한 빌드 이슈 해결 완료
