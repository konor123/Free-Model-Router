## Goal

Phase 6.5 OpenCode-only 런타임 통합을 시작하여, 프로바이더 디스커버리를 routes/pool에 투영하고 정책 필터링을 통해 게이트웨이 후보를 결정한다.

## Actions

- 게이트웨이 카탈로그 갱신 시 `opencode.Routes`를 사용하여 라우트를 구체화(materialized).
- 발견된 free-route 모델을 Automatic 풀에 조정(reconciled).
- `router.Filter`를 사용하여 결정론적 게이트웨이 후보 리졸버를 추가.
- 유료 routes는 자동 후보에서 제외한다는 사용자 결정을 적용.
- 런타임 투영 회귀 테스트 커버리지를 추가하고, 명시적 Go/WinLibs 경로를 사용하여 로컬 race, vet, 빌드 게이트를 성공적으로 통과.

## Files Changed

- `internal/gateway/gateway.go`: 라우트/풀 투영 및 필터링된 후보 리졸루션 로직 추가.
- `internal/gateway/gateway_test.go`: 투영된 라우트 및 Automatic 풀 테스트 추가.

## Result

- **성공**: 로컬 `go test ./... -race`, `go vet ./...`, `go build ./cmd/Free-Model-Router` 모두 통과.
- 독립 리뷰는 OCR 전제 정책에 의해 차단됨; 코드 관련 발견 없음.

## Next Steps

- Phase 6.5를 계속 진행: 앱 소유 런타임/카탈로그 갱신, 헬스 및 지연 시간을 실제 요청 실행에 연결한 후, 전체 mock-server E2E 테스트를 추가한다.
