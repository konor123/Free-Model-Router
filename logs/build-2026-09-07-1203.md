## Goal

데스크톱 플랜에서 요구하는 모델 매니저 컨트롤을 구현합니다.

## Actions

- 클라이언트 측 통합 검색, 프로바이더, 접근성, 가용성/선택, 고정, 기능 필터링을 추가했습니다.
- 전체 선택, 전체 해제, 표시된 것 선택, 표시된 것 해제, 고정/고정 해제, 자동 선택 액션을 추가했습니다.
- 각 모델 변경 사항을 리비션 인식 Tauri 제어 브리지를 통해 라우팅하고 실패 시 재시도 안내를 추가했습니다.
- 결합된 모델 필터링에 대한 프론트엔드 유닛 테스트를 추가했습니다.
- 데스크톱 프론트엔드 테스트 모음을 성공적으로 실행했습니다.

## Files Changed

- `desktop/frontend/app.js`: 모델 필터 상태, 컨트롤, 대량 액션, 고정/자동 핸들러, 테스트 전용 상태 훅을 추가했습니다.
- `desktop/frontend/app.test.js`: 모델 필터 동작 커버리지를 추가했습니다.

## Result

- 성공: `npm.cmd test --prefix desktop` 테스트 2개 통과.
- 모델 매니저는 이제 인증된 네이티브 셸을 통해 전체 선택된 모델 풀과 고정 상태를 관리할 수 있습니다.

## Next Steps

- REST 조정과 함께 Rust 소유 인증 SSE 릴레이를 추가.
