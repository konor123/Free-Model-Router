## Goal

Free-Model-Router v0.8.0 릴리스 — 스키마 v2 Provider 설정, 단일 창 데스크톱 UI, 모델 지표·재탐색, 보안 키 관리, 트레이 단순화, Windows 릴리스 산출물까지 end-to-end를 완료한다.

## Actions

- 스키마 v2 `ProviderConfig`와 안전한 마이그레이션(`Config.Migrate`), URL 검증을 도입했다.
- `internal/providers/registry`, `internal/providers/openaicompat`로 OpenAI 호환 어댑터와 다중 Provider registry, route 소유권 기반 dispatch를 구현했다.
- 카탈로그 refresh를 staged reconciliation으로 전환하고 `POST /_fmr/catalog/refresh` 엔드포인트를 추가했다.
- 인증된 config GET/PUT API, optimistic revision, 쓰기 전용 Provider key, inference key 교체·삭제·생성, `SecretStore` transaction/cleanup 상태를 연결했다.
- Provider endpoint 변경 시 기존 key를 명시적으로 교체/삭제하도록 강제하고 provider 전용 secret reference만 허용하도록 검증했다.
- 데스크톱을 Provider / Model / Usage log / Endpoint-key 단일 창 4탭으로 통합하고 Provider 편집, key masking, 모델 정렬, unknown `-`, Rediscover 액션을 추가했다.
- desktop-managed 설정 변경은 자동 재시작하고 external 변경은 restart-required 뱃지로 표시하도록 했다.
- 트레이를 `Start with Windows` + `Exit`로 단순화하고 좌클릭 시 창 표시, 마지막 성공 모델 tooltip을 구현했다.
- Tauri installer에 gateway sidecar, metadata, `fmr` CLI를 실제로 포함하도록 `tauri.conf.json` 리소스·번들과 `release-windows.yml` 워크플로를 수정했다.
- 한국어 `README.md`, `desktop/README.md`, `packaging/windows/README.md`와 `RELEASE_NOTES_v0.8.0.md`를 작성했다.

## Files Changed

- `internal/config/*`: Provider 스키마 v2, 마이그레이션, URL·secret reference 검증, strict secret cleanup.
- `internal/provider/provider.go`, `internal/providers/registry/*`, `internal/providers/openaicompat/*`: routed multi-provider 기반.
- `internal/catalog/*`, `internal/gateway/gateway.go`: staged catalog refresh + `/_fmr/catalog/refresh`.
- `internal/control/*`, `internal/app/*`: config GET/PUT, optimistic revision, persistence, secret transaction, startup wiring.
- `desktop/frontend/*`: 단일 창 탭, Provider/endpoint 폼, 모델 지표 및 정렬, 테스트.
- `desktop/src-tauri/*`: config bridge, managed restart, 트레이 단순화, tooltip, v0.8.0 번들 리소스.
- `.github/workflows/release-windows.yml`: sidecar 준비 + GitHub Release 발행.
- `README.md`, `desktop/README.md`, `packaging/windows/README.md`, `RELEASE_NOTES_v0.8.0.md`: 한국어 문서.
